# Registration Form App 📱

Aplikacija za Android, ki služi kot demonstracija uporabniškega vmesnika za registracijo, prijavo ter obnovitev gesla, zasnovana po vzoru Instagramovega vmesnika. Projekt vključuje več različnih zaslonov (aktivnosti) in interaktivnih elementov za vnos in preverjanje podatkov.

---

## 🚀 Ključne lastnosti (Funkcionalnosti)
* **Prijava (Login):** Vnos uporabniškega imena, e-pošte ali telefonske številke ter gesla z validacijo.
* **Registracija (Register):** Obrazec za ustvarjanje novega računa, ki vključuje vnos datuma rojstva (z dinamičnim preverjanjem starosti) in kontaktne podatke.
* **Potrditev kode (Confirm):** Vnos 6-mestne potrditvene kode za aktivacijo računa.
* **Ponastavitev gesla (Reset):** Možnost iskanja računa in obnovitve dostopa.
* **Uporabniški vmesnik:** Prilagojen in čist dizajn, ki uporablja moderne elemente (pogovorna okna oz. modale, drsenje zaslona, validacijo vnosnih polj).

---

## 🛠️ Uporabljene tehnologije in gradniki
* **Jezik:** HTML / CSS / JavaScript (ali Android XML / Java/Kotlin za mobilno aplikacijo)
* **Ključni gradniki:**
  * `ScrollView` / `ScrollViewer` za drsenje po celotnem obrazcu na manjših zaslonih.
  * `EditText` za vnos besedila, e-pošte in gesel.
  * `RadioGroup` in `RadioButton` / spustni meniji (`select`) za izbiro datumov in možnosti.
  * `AlertDialog` / Modalna okna za prikaz obvestil, napak in povzetkov podatkov.
  * `CheckBox` za potrjevanje pogojev.
